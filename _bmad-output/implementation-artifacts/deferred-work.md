## Deferred from: story-1-5-base-app-shell-responsive-layout dev-story (2026-08-18)

- **Neon free-tier branch limit (10) is now a recurring, live operational problem**, not just the theoretical risk architecture's own review (`review-version-check.md`, finding F7) flagged. Leaked `test-*`/`test-e2e-local-*` branches from interrupted/timed-out local runs (cleanup-on-exit is best-effort and doesn't reliably fire when a process is force-killed on Windows) have hit the hard cap twice now (Stories 1.4 and 1.5), each time requiring manual cleanup via the Neon API before any further test run could create a new branch. Needs a real fix: either a scheduled/pre-run cleanup script (delete `test-*` branches older than N hours), upgrading the Neon plan for a higher branch cap, or both.
